# Portafolio de Jhon

Portafolio estatico en HTML, CSS y JavaScript, publicado desde GitHub Pages.

## Estructura

| Archivo | Funcion |
| --- | --- |
| `index.html` | Pagina principal, textos, proyectos y contacto. |
| `style.css` | Colores, tipografia y adaptacion a celular. |
| `script.js` | Interaccion para abrir y cerrar la pieza visual ampliada. |
| `img/proyecto-01-muestra.webp` | Imagen de ejemplo generada con IA, pendiente de reemplazar. |
| `.nojekyll` | Publica los archivos estaticos directamente en GitHub Pages. |

## Estado del contenido

- Proyecto de muestra: `Orbita`.
- Imagen de muestra: generada con IA para maqueta, no representa un cliente real.
- Contacto: pendiente de agregar.
- Pie de pagina: marcado como portafolio en preparacion.

## Actualizacion

Para personalizar el portafolio, edita los textos marcados con comentarios `EDITAR` en `index.html`, reemplaza la imagen de muestra en `img/` y actualiza los datos de contacto.
